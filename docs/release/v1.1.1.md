# repl-lang v1.1.1

A patch release with two editor fixes. There are no API changes.

## Fixed

- **Bidirectional formatting characters are dropped.** U+061C, U+200E, U+200F, U+202A to U+202E and U+2066 to U+2069 are invisible and change how the text around them is displayed, so a line holding them could show something other than what it contains. Typing, pasting and recalled history now drop them, as they already dropped control characters. Zero-width joiners and combining marks are ordinary text and are kept.
- **History browsing no longer skips an entry.** If the history was full and being browsed at its oldest entry, recording a new entry dropped the one being shown and left the browse pointing one entry ahead, so `HistoryNext` skipped an entry. It now moves to the oldest entry that is left, and `HistoryPrev` reports that there is nothing older.

MSRV is unchanged at Rust 1.85.
